# BillSplit - Roommate Expense Splitter

BillSplit is a modern Android application designed for roommates and groups to record shared expenses, calculate equal and custom expense splits, track individual balances, settle up debts, and generate spending reports.

## Features
- **Dashboard**: Track overall balances, you owe, owed to you, and recent expenses.
- **Group Management**: Create custom groups, manage roommate members dynamically, and switch active groups.
- **Custom Expense Splitting**: Supports Equal Split, Exact Amount Split, and Percentage Split (%) with integer paise precision.
- **Individual Balances & Simplified Debts**: Automatic net balance calculation and simplified debt pairing.
- **Settle Up & Settlement History**: Record full or partial payment settlements between members.
- **Expense Reports**: View total spending, top spending categories, category breakdowns, and member payment shares.
- **User Profile**: Update profile information, view currency settings (₹ INR), and sign out.
- **Node.js REST API Backend**: Modular Express.js, MongoDB, Mongoose backend with JWT authentication and BCrypt password hashing.

## Tech Stack
- **Android App**: Java, XML, Material Components, Retrofit 2, Gson, OkHttp
- **Backend API**: Node.js, Express.js, MongoDB, Mongoose, JWT, BCrypt
